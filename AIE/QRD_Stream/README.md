# QRD Stream (QR Decomposition)

Stream IO variant of the QRD block for AI Engine solver designs.

![](./Images/block.png)

## Library

AI Engine/Solver/Stream IO

## Description

This block provides the same QR decomposition capability as the [buffer IO QRD block](../QRD/README.md), using stream interfaces instead of buffer IO. Parameter names and supported ranges match the buffer variant.

See *AI Engine Solver Blocks* in UG1483 for matrix layout assumptions.

## Parameters

Parameters match the [QRD](../QRD/README.md) block. See that topic for parameter descriptions.
